싹비움 개인정보처리방침

시행일: 2026-09-12 · 개정: 2026-09-29

1. 계정 없이 쓰는 경우

싹비움은 계정 없이도 모든 기본 기능을 쓸 수 있습니다. 이 경우 이름·이메일·전화번호 등 개인을 식별할 수 있는 정보를 수집하지 않으며, 등록한 식품 이름, 유통기한, 보관 장소, 수량, 메모, 가격, 유통기한 촬영 사진, 먹었어요·버렸어요 기록은 모두 사용자의 기기 안에만 저장됩니다.

2. 계정을 만들어 룸메와 냉장고를 함께 쓰는 경우

«내 정보 › 계정 설정»에서 계정을 만들면 아래 정보를 수집·저장합니다. 계정은 선택 사항이며, 룸메와 냉장고를 함께 관리할 때만 필요합니다.

항목목적보관 위치
이메일, 비밀번호(암호화 저장)로그인, 비밀번호 변경·재설정Google Firebase(서울 리전) 서버
닉네임룸메에게 표시
프로필 사진(선택)룸메에게 표시
함께 쓰는 냉장고의 식품 정보(이름, 바코드 번호, 카테고리, 유통기한, 보관 장소, 수량, 메모, 가격, 먹었어요·버렸어요 기록)같은 냉장고를 쓰는 룸메 사이의 동기화

유통기한 촬영 사진은 계정을 만들어도 서버로 전송되지 않고 기기 안에만 남습니다. 식품 정보는 같은 냉장고에 참여한 룸메에게만 보이며, 그 밖의 사용자나 제3자에게 공개되지 않습니다.

3. 외부로 전송되는 정보

바코드를 스캔해 상품 정보를 찾을 때 아래 곳으로 바코드 번호가 전송됩니다. 이름·이메일 등 개인을 식별할 수 있는 정보는 함께 전송되지 않습니다.

  • 식품의약품안전처(식품안전나라)와 한국식품안전관리인증원의 공공 API
  • 싹비움 상품 정보 저장소(Google Firebase Cloud Firestore, 서울 리전): 다른 사용자가 이미 찾은 상품 정보를 바코드 번호로 조회합니다.
  • 싹비움 상품 조회 서버(Google Firebase Cloud Functions, 서울 리전): 공공 API에 없는 상품은 서버가 바코드 번호로 네이버·카카오 웹 검색을 조회해 상품 이름을 찾고, 찾은 상품 정보(이름·분류 등)를 위 저장소에 남깁니다. 요청을 보낸 기기의 IP 주소는 과도한 요청을 막는 데에만 쓰며, 기록에는 원래 주소가 아닌 변환값(해시)만 남깁니다.

계정에 로그인한 상태에서 상품 이름을 직접 입력하면 그 바코드의 상품 정보(이름·분류 등)가 위 저장소에 저장되어, 같은 바코드를 스캔하는 다른 사용자에게 보일 수 있습니다. 누가 입력했는지는 저장하지 않습니다.

4. 카메라·사진

카메라는 바코드, 유통기한, 룸메 초대 QR 코드를 스캔할 때만 사용합니다. 사진 보관함은 사용자가 «앨범에서 찾기»나 프로필 사진 선택을 직접 눌렀을 때, 고른 사진 한 장에만 접근합니다.

5. 알림

유통기한 알림과 주간 리포트 알림은 기기의 로컬 알림으로만 동작하며 서버를 거치지 않습니다.

6. 구매

앱 내 구매는 Apple App Store를 통해 처리되며, 개발자는 결제 정보를 받지 않습니다.

7. 보관 기간과 삭제

계정 정보와 서버에 저장된 식품 정보는 계정을 유지하는 동안 보관됩니다. «내 정보 › 계정 설정 › 회원 탈퇴»를 누르면 계정, 프로필, 프로필 사진이 즉시 삭제됩니다. 룸메와 함께 쓰던 냉장고의 식품 정보는 남은 룸메에게 그대로 남고, 혼자 쓰던 냉장고의 식품 정보는 함께 삭제됩니다. 계정을 만들지 않은 경우 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.

8. 처리 위탁

계정과 동기화 데이터, 상품 정보 저장소의 저장·처리와 상품 조회 서버 운영을 위해 Google LLC의 Firebase(Authentication, Cloud Firestore, Cloud Functions, 서울 리전)를 이용합니다. Google은 위탁 목적 밖으로 데이터를 이용하지 않습니다.
